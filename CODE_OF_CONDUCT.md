# Code of conduct

Relay adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. In short: be respectful and welcoming, assume good faith, and keep discussions about the work.

It applies in every project space (issues, pull requests, discussions) and when representing the project elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainer, [@sebasBetancourt](https://github.com/sebasBetancourt), for example through a private message on GitHub. Reports are handled confidentially, and the maintainer may remove, edit or reject contributions, or ban participants, following the Covenant's enforcement guidelines.
